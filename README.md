# Agent Skills Repository

This repository contains agent skills I use in my daily work. Some are original; others are adapted to fit my workflows and use cases.

## Skills

The collection currently contains 21 skills under [`skills/`](skills/). See the [skills catalog](skills/README.md) for their purposes and invocation modes.

## Claude Plugin

The Claude plugin manifest is defined in [`.claude-plugin/plugin.json`](.claude-plugin/plugin.json). It registers every skill in the collection using the flat `skills/<name>/` layout.
